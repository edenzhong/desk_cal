# macOS 桌面日历 - 项目规格文档

## 项目概述
开发一个 macOS 桌面日历应用，通过动态墙纸技术在桌面背景上展示一整年的日历视图，并高亮显示当前日期。日历将根据显示器分辨率自适应生成图片并设置为系统墙纸，提供美观的视觉体验。

## 目标
- 生成包含全年日历的图片，设置为 macOS 桌面墙纸
- 日历在桌面上持续显示（非仅在显示桌面时）
- 显示一整年（12 个月）的日历网格
- 突出显示今天的日期（例如用圆圈或高亮背景）
- 支持主显示器，扩展显示器可选支持
- 界面设计美观、简洁、易读，风格参考系统自带日历
- 每天自动更新墙纸，确保日期准确

## 功能需求

### 核心功能
1. **图片生成**
   - 根据当前年份生成包含12个月日历的图片
   - 自适应显示器分辨率，优化布局和字体大小
   - 支持透明或纯色背景，可适配用户现有墙纸

2. **日历显示**
   - 显示当前年份的完整日历（12 个月）
   - 每个月份显示月份名称、星期标题（日、一、二、三、四、五、六）
   - 日期数字按正确的星期排列
   - 支持年份切换（可选增强功能）

3. **今日高亮**
   - 在日历中突出显示当前日期
   - 高亮样式：圆形边框、背景色变化或类似视觉强调
   - 每天自动更新墙纸以更新高亮位置

4. **墙纸设置**
   - 将生成的日历图片设置为 macOS 桌面墙纸
   - 支持主显示器，可选支持扩展显示器
   - 保持用户现有墙纸风格（如模糊、填充、拉伸等设置）

5. **定时更新**
   - 每天自动更新墙纸，确保日期准确
   - 检测日期变更（如跨年、跨月）时重新生成
   - 低资源消耗，仅在需要时运行

### 非功能需求
1. **性能**
   - 启动时间快，不影响系统启动
   - 内存占用低（< 50 MB）
   - CPU 使用率低（空闲时接近 0%）

2. **可靠性**
   - 应用稳定，不崩溃
   - 日历显示准确，正确处理闰年、月份天数等
   - 窗口层级保持正确，不会意外遮挡其他应用

3. **用户体验**
   - 界面美观：字体、颜色、间距协调
   - 日历易读：即使在远距离或小字号下也清晰可辨
   - 自适应布局：根据屏幕分辨率优化月份排列

4. **兼容性**
   - 支持 macOS 11.0 (Big Sur) 及以上版本
   - 支持 Intel 和 Apple Silicon 芯片

## 用户场景
1. **日常查看日期**
   - 用户在桌面上即可直接查看当前日期和全年日历
   - 用户需要计划未来日期时，可直观看到整年布局
   - 每天自动更新，确保日期准确

2. **美化桌面**
   - 用户希望桌面背景既有美感又有实用性
   - 日历作为装饰性元素，同时提供实用功能
   - 风格与 macOS 系统日历一致，保持视觉协调

3. **自动化更新**
   - 应用后台运行，每天自动更新墙纸
   - 无需用户手动操作，始终保持最新日期
   - 低资源占用，不影响系统性能

## 技术约束
- 使用 macOS 原生 API 设置桌面墙纸（NSWorkspace）
- 图片生成需考虑不同分辨率、DPI（Retina 显示）
- 应用应作为后台服务运行，不干扰用户正常使用
- 每天定时更新，资源消耗最小化
- 处理用户手动更改墙纸的情况（可选：检测并恢复）

### 增强功能需求
1. **农历日期显示**
   - 在每个公历日期下方显示对应的农历日期
   - 支持农历日期格式配置（如显示"初一"、"十五"或"3/5"等）
   - 通过配置文件控制是否显示农历（`show_lldar_date: true/false`）
   - 农历日期字体大小和颜色可配置
   - 在农历重要节日日（如春节、中秋）添加特殊标记

2. **国家假期信息显示**
   - 在日历上标记中国法定节假日（如春节、国庆、清明等）
   - 区分工作日与节假日（包括调休日）
   - 支持假期信息缓存机制，减少API调用
   - 通过配置文件控制是否显示假期信息（`show_holidays: true/false`）
   - 假期标记样式可配置（背景色、边框、图标等）

## 开放问题（已确认）
1. **外观自定义**：作为后期优化功能，初始版本暂不考虑，但设计上保留扩展接口
2. **多显示器配置**：非必须，如果程序不复杂则可增加此功能，如果需要为此显著影响程序的架构或显著增加资源占用，则放弃
3. **交互功能**：不需要
4. **动态更新**：不需要

## 成功标准
- 日历正确显示在桌面背景上
- 今天日期明显高亮
- 每天自动更新墙纸，日期准确
- 界面美观，风格与系统日历协调，用户满意度高
- 应用稳定，资源占用低，后台运行不干扰用户
